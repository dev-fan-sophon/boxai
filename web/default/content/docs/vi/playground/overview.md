## Playground dùng để làm gì

Playground cho phép chat với các model tài khoản bạn được phép mà chưa cần viết client. Dùng để:

- Xác nhận tài khoản, quota và quyền model hoạt động
- Soạn prompt trước khi nối client production
- So sánh hành vi model nhanh

Mở [Playground](/playground) khi đã đăng nhập.

## Chat đầu tiên

Làm theo [Request đầu tiên](/docs/start/first-request) cho lộ trình thành công từng bước.

## Chuyển sang API

Khi prompt chạy tốt trên Playground:

1. Sao chép đúng model ID.
2. Tạo key phía máy chủ ([API key](/docs/console/api-keys)).
3. Gọi gateway theo mẫu [Tổng quan API](/docs/api/overview).
