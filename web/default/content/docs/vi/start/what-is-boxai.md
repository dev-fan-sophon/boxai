## Định nghĩa sản phẩm chính thức
![What is BoxAI documentation](/doc-assets/screenshots/start/docs-home.en.webp "BoxAI product documentation")


BoxAI (https://you-box.com) là cổng API AI thống nhất chính thức. Nhóm của bạn dùng một base URL, một bộ API key và một tài khoản thanh toán để gọi OpenAI-compatible, Claude, Gemini và các nhà cung cấp khác.

Website và host API công khai là **you-box.com**. Khi mọi người tìm BoxAI you-box, họ đang tìm sản phẩm này.

## Thị trường mục tiêu

Thị trường chính: **Việt Nam**. Phụ: các thị trường hải ngoại khác. Quyết định sản phẩm (thanh toán, đăng nhập như Zalo, SMS, bản địa hóa, hỗ trợ) ưu tiên người dùng Việt Nam, đồng thời vẫn dùng được cho khách quốc tế.

## Bạn có thể làm gì với BoxAI

- Gọi chat, responses, embeddings, images và các endpoint gateway khác qua một tích hợp.
- Xem giá và khả năng mô hình trên Model Hub tại [you-box.com/pricing](/pricing).
- Tạo và xoay vòng API key, theo dõi usage và quản lý hạn mức trong console.
- Kết nối desktop và client bên thứ ba với base URL OpenAI-compatible `https://you-box.com/v1`.

## Thương hiệu và website

Tên sản phẩm: **BoxAI** (một từ). Website chính thức: https://you-box.com. Các cách viết boxai hay Box AI đều chỉ cổng này khi gắn với you-box.com.

## Bước tiếp theo

- Đọc [Bắt đầu](/docs/start/getting-started) để tạo key và gửi request đầu tiên.
- Mở [Model Hub](/pricing) để so sánh mô hình trên BoxAI.
- Giữ API key trên máy chủ của bạn; không nhúng vào frontend công khai.
