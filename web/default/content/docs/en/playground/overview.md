## What Playground is for

Playground lets you chat with models available to your account without writing client code first. Use it to:

- Validate that your account, quota, and model access work
- Draft prompts before wiring production clients
- Compare model behavior quickly

Open [Playground](/playground) while signed in.

## Move to the API

When a prompt works in Playground:

1. Copy the exact model ID.
2. Create a server-side key ([API keys](/docs/console/api-keys)).
3. Call the gateway using [API overview](/docs/api/overview) samples.
