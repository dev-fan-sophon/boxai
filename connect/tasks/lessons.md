# Connect lessons

- Core discovery includes legacy adapters for restoration. Every visible count,
  list, and denominator must use the distribution's supported-agent set; test
  with a detected unsupported adapter and an undetected supported adapter.
- Native fixture screenshots must be inspected for numeric consistency as well
  as clipping, language, and layout. A read-only fixture is not live auth/apply
  evidence, and acceptance features must never enter distributed installers.
